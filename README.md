# 📄 Pagination Component

A simple and reusable pagination component built with React and Vite.  
This project demonstrates how to efficiently split large datasets into pages and navigate between them.



# 🚀 Features

- Dynamic page calculation based on dataset size
- Previous / Next navigation buttons
- Active page highlighting
- Disabled states for edge navigation
- Clean and reusable component structure
- Fast performance using React state management



# 🧠 How It Works

The pagination component works by:

1. Receiving a dataset (array of items)
2. Defining how many items appear per page
3. Calculating total number of pages
4. Using state to track the current page
5. Slicing the dataset based on the active page
6. Updating the UI when navigation buttons are clicked



# 🛠️ Tech Stack

- React
- Vite
- JavaScript (ES6+)
- CSS
